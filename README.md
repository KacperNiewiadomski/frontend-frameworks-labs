# Frontend Frameworks – Laboratories

Repository containing laboratory assignments completed as part of the **Frontend Frameworks** course at **DSW Ideis University, Kraków**.

**Academic Year:** 2026/2027

## About

This repository contains practical assignments focused on learning modern frontend technologies, frameworks, and development practices.

Each laboratory is maintained in a **separate Git branch**, allowing assignments to be developed, reviewed, and accessed independently.

## Laboratories

| Laboratory | Topic | Branch |
|---|---|---|
| Lab 01 | Book Catalog – React Components, TypeScript, CSS Modules & Filtering | [lab-01](https://github.com/KacperNiewiadomski/frontend-frameworks-labs/tree/lab-01) |

*The list will be updated as new laboratories are completed.*

## Branch Organization

The repository follows a branch-based structure:

- **`master`** – Repository overview and documentation.
- **`lab-01`** – Laboratory 1: Book Catalog application.
- **`lab-XX`** – Subsequent laboratory assignments.

Each laboratory branch contains its own source code, configuration, and project files.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/KacperNiewiadomski/frontend-frameworks-labs.git
```

Navigate to the project directory:

```bash
cd frontend-frameworks-labs
```

Switch to the desired laboratory branch:

```bash
git switch lab-01
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

To create a production build:

```bash
npm run build
```
